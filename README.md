# Codebility Portal

> Internal platform web app development portal for Codebility — built to manage team workflows, announcements, points/leaderboards, and role-based access for all developers in the company. Architected and deployed full-stack features using React.js, Node.js, TailwindCSS, and Supabase in a production-grade internal platform. Enforced code quality standards through peer code reviews and Git-based workflows. Owned cross-browser and device QA testing pipeline, ensuring responsiveness and release readiness.

## 🧩 Challenges & Solutions

- **Challenge:** Tab order in the Announcement Modal was static, limiting user flexibility.
  **Solution:** Implemented drag-and-drop reordering, improving usability for managing multiple announcement tabs.

- **Challenge:** Team management form had inconsistent spacing/alignment across components.
  **Solution:** Refactored layout using Tailwind utility classes and Radix UI primitives for consistent, accessible structure.
